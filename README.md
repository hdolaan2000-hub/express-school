# Экспресс Школа — экран «Главная»

Вёрстка экрана из Figma ([node 2:514](https://www.figma.com/design/fiNBSzeOiCsCP2wpxsFMS4/?node-id=2-514)).

## Стек

- **React 19 + Vite + TypeScript**
- **CSS Modules** — обычный CSS с точными значениями из макета, изоляция по компонентам
- Никаких UI-библиотек и рантайм-зависимостей кроме React

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # прод-сборка в dist/
```

## Как устроена вёрстка

Макет нарисован как одна сцена шириной **1440×1662** с абсолютным позиционированием
всех блоков — вёрстка повторяет эту структуру один в один:
[App.tsx](src/App.tsx) держит сцену и расставляет карточки по координатам из Figma,
каждый компонент отвечает за свою внутреннюю раскладку.

### Адаптивность

Поведение задано двумя макетами — «Home» (1440) и «Home Big» (1958), см.
[useStageScale.ts](src/hooks/useStageScale.ts):

- **Шире 1440** — ничего не масштабируется. Сайдбар шириной 250 прижат влево, блок
  карточек фиксированной ширины 1158 центрируется в оставшемся пространстве, по бокам
  появляются поля. Приветствие и иконки прижаты к краям экрана.
- **Уже 1440** — места для этого нет, поэтому сцена целиком сжимается через
  `transform: scale()`. Горизонтального скролла не возникает.

Обе ветки сходятся на 1440: `250 + (1440 − 250 − 1158) / 2 = 266` — ровно координата
блока карточек в исходном макете.

### Структура контента

Актуальный макет собран на auto-layout, поэтому блок контента (1158px) — это
вертикальный стек ([App.tsx](src/App.tsx)) с шагом 32px:

1. **Баннеры + сетка плиток** — flex-ряд из двух промо-баннеров и grid 3×2, где
   карточка прогресса занимает третий столбец на две строки.
2. **Ряд «Квест + Друзья»** — карточка квеста (767) и лидерборд друзей (376) одной
   высоты 696px.
3. **Нижний ряд** — три карточки контента («Секреты здоровой еды»).

Между секциями — разделительные линии, как в макете. Карточки внутри сохраняют
собственную вёрстку.

### Известное расхождение

В «Home Big» приветствие стоит на x=297, а иконки в 37px от правого края. В «Home»
те же элементы дают 266 и 16px. Единого правила из двух макетов не выводится, поэтому
взяты отступы из «Home» — на 1440 всё сходится точно, на широких экранах приветствие
левее макета на 30px, иконки правее на 21px. **Нужно уточнить у дизайнера.**

Если позже понадобится настоящий резиновый режим (карточки перестраиваются в 2/1 колонку) —
это уже дизайнерское решение, которого в макете нет, его нужно рисовать.

## Мини-игра «Запоминайка»

Экран из [node 145:1828](https://www.figma.com/design/rbOutY6P00pswSk3YrEbyZ/?node-id=145-1828),
карточка — [компонент 145:2303](https://www.figma.com/design/rbOutY6P00pswSk3YrEbyZ/?node-id=145-2303).
Хэш `#game`, плитка «Мини-игра» на главной ведёт сюда.

- [MemoryCard](src/components/MemoryCard/MemoryCard.tsx) — три состояния компонента:
  `Default` (рубашка), `Clicked` (открыта), `Pair` (угадана, заливка `#f5f5f5` + пунктир `#e5e5e5`).
- [MemoryGameScreen](src/screens/MemoryGameScreen.tsx) — шапка, поле 5×4 и итоговый диалог
  (`mini-game-win` / `mini-game-lose`).

### Правила

10 пар, 24 хода, +2 очка за пару — числа взяты из счётчиков в шапке макета.
Ход списывается при открытии второй карточки. Все пары собраны → «Ты победил!»,
ходы кончились → «Ты проиграл...». Рекорды и уровни не сохраняются — по указанию дизайнера.

В начале партии все карточки лежат открытыми 2 секунды, затем закрываются каскадом
с шагом 40 мс — переворот идёт волной, а не одномоментно.

### Анимация и звук

Переворот — `rotateY(-180deg)` (направо) на внутреннем слое, лицо и рубашка
разведены через `backface-visibility`, у каждой карточки своя `perspective: 800px`,
чтобы точка схода была в её центре независимо от места в сетке.

Длительность **220 мс** снята покадрово с видео-референса дизайнера: на 30 fps карточка
уходит в ребро за 4 кадра и раскрывается за 7. Оттуда же вырезан звук перелистывания —
[card-flip.mp3](public/assets/card-flip.mp3) (фрагмент 2.63 с, нормализован по громкости).
Звук играет в начале каждого переворота; в стартовом каскаде — тише (0.35), чтобы 20 щелчков
подряд не превращались в шум. При `prefers-reduced-motion` вращение отключается.

Автоплей до первого клика браузер может заблокировать — ошибка `play()` гасится,
на переход с главной (клик по плитке) активация уже есть.

### Расхождения с макетом

- **Рубашка карточки** — в макете это растровый экспорт. Пересобрана как
  [card-back.svg](public/assets/card-back.svg) (пунктирный прямоугольник 200×167 + точка):
  выгрузить оригинал из Figma не удалось, зато вектор не мылится при масштабировании сцены.
- **Заголовок шапки** — в макете auto-layout поставил текстовую ноду не по центру строки,
  а со сдвигом влево на ~8px. Воспроизведено как есть (бокс 287.547px, текст на 191.98px).
- **Тень кнопки «Заново»** — в этом макете `0 4px 6px`, в остальных экранах проекта та же
  кнопка идёт с `0 4px 12px`. Оставлена проектная, чтобы кнопки не разъезжались между экранами.
- **Эмодзи на карточках** — в макете нарисованы только 🍅 и 🥒. Для 10 пар добавлены ещё
  восемь овощей в ту же тему. **Нужно уточнить у дизайнера.**

## Шрифт

В макете — **SF Pro Rounded** (часть подписей размечена как Geist). Гарнитура не
раздаётся с CDN, поэтому подключён системный файл macOS `/System/Library/Fonts/SFNSRounded.ttf`,
скопированный в [public/fonts/](public/fonts/) — с ним переносы строк и метрики
совпадают с Figma.

⚠️ **Для продакшена** шрифт нужно заменить на официальный пакет
[Apple SF Pro](https://developer.apple.com/fonts/) и соблюсти его лицензию, либо
подобрать свободную rounded-гарнитуру. Файл в репозитории — временное решение для разработки.

## Точность

Расхождения с макетом замерялись попиксельно: рендер страницы сравнивался с эталонным
экспортом из Figma ([reference/home-full.png](reference/home-full.png)).

Текущее состояние — **отклонение позиций текста и декора в пределах ±1–2px**.
Остаточные различия и их причины:

- **Эмодзи** (⭐, 🥇, 👋🏻, ❤️) — Figma и браузер рисуют их разными шрифтами,
  глифы отличаются по размеру на 2–4px. Средствами CSS не устраняется.
- **Мелкие подписи** («75/100», «Уровень 7») — в макете размечены гарнитурой Geist.
  Ширины текстовых нод заданы явно по значениям из Figma, поэтому позиции совпадают,
  но сами глифы чуть отличаются.
- **Фотография квеста** — разница только от передискретизации 1024→727px.

## Ассеты

Иконки и иллюстрации выгружены из Figma через MCP в [public/assets/](public/assets/).
Повёрнутые декоративные элементы выгружены в PNG (@3x): их SVG-экспорт приходит без
поворота, поэтому размеры не сходились с макетом.
